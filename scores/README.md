# 历年分数线数据

每个研究所只维护一个 Markdown 文件，普通计划、退役大学生士兵计划和少数民族高层次骨干人才计划都写在同一个文件中。首页会按二级标题自动拆分并汇总到三个板块。

文件名由 `site-config.js` 中的 `scoreFile` 指定。例如，信工所的三类计划统一维护在 `scores/iie.md`。

新增数据文件时可以参考 `example.md`。该文件没有配置给任何研究所，仅用于展示填写格式，不会被首页解析。

## 表格格式

三个二级标题和表头名称需要保持不变，直接填写各表预留的近三年数据：

```md
## 普通计划

| 年份 | 类型 | 专业 | 专业课代码 | 政治 | 英语 | 数学 | 专业课 | 总分线 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026 | 学硕 |  |  |  |  |  |  |  |
| 2026 | 专硕 |  |  |  |  |  |  |  |
| 2025 | 学硕 |  |  |  |  |  |  |  |
| 2025 | 专硕 |  |  |  |  |  |  |  |
| 2024 | 学硕 |  |  |  |  |  |  |  |
| 2024 | 专硕 |  |  |  |  |  |  |  |

## 退役大学生士兵计划

| 年份 | 类型 | 专业 | 专业课代码 | 政治 | 英语 | 数学 | 专业课 | 总分线 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026 | 学硕 |  |  |  |  |  |  |  |
| 2026 | 专硕 |  |  |  |  |  |  |  |

## 少数民族高层次骨干人才计划

| 年份 | 类型 | 专业 | 专业课代码 | 政治 | 英语 | 数学 | 专业课 | 总分线 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 2026 | 学硕 |  |  |  |  |  |  |  |
| 2026 | 专硕 |  |  |  |  |  |  |  |
```

- `类型`填写`学硕`或`专硕`。
- `专业课代码`填写`408`、`866`等考试科目代码。
- `政治`、`英语`、`数学`、`专业课`分别填写对应的单科线。
- `-`表示不限制，`？`表示数据缺失。
- 每个“年份 + 类型 + 专业”对应一行；同一年可以增加多行填写不同专业。
- 年份行可以自由增加或删除，不要求每年都同时填写学硕和专硕。
- 首页按当前年份自动只显示最近三年。当前日期为 2026 年时，展示 2024、2025、2026 年；旧数据可以继续保留，不需要手动删除。
- 新增年份后不需要修改 JavaScript 或 HTML，进入最近三年范围后会自动显示。
- 三个计划板块分别支持按研究所、年份、专业课代码和学硕/专硕类型组合筛选，彼此互不影响。
- 未填写的预留行不会显示在首页；填写总分线后，该行才会被解析为有效数据。
- 新增研究所时只需新建一个文件，并保留三类计划的二级标题和表格。
